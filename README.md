# robocomp

This is a publication of our final product in the Robocompetition 2026 organized by FEL CTU.

Goal: Construct and programme a robot that is able to build a valid domino sequence.

## Files

config.py - converts bare motor values to length and radius via human-readable functions (e.g. jed_cm(length: int))

simple_test.py - progrm that we used for the first run

final.py - program that we used for the second and last run

## AI Element

The config.py file was vibecoded, however we had to cnfigure the coefficients ourselves based on testing. Other files were then written manually and adjusted.
